Source Link Check Guide

Manually spot redirects, page changes, missing options, and unavailable links along the trail.

Read the destination, not the label

A Sheet link is a label. The page it opens is the destination. Read the destination — its title, domain, and final address — before trusting the label.

Signals to watch for

Redirect

The link settles somewhere different from where it pointed. Note the final destination rather than the original address.

Page changed

The page’s title or layout no longer matches the clue. Re-read what the page actually shows now.

Option missing

A color, size, or version is gone. Re-check what is actually selectable on the current page.

Link unavailable

The link does not open a usable page. Stop and locate a current link instead.

?Open question: did the link open where the label said it would?

A worked check

  1. Label: the row points to a bag on a store page.
  2. Destination: the opened page names the bag and matches the domain.
  3. Options: the color and size you wanted are still selectable.
  4. Result: the trail is clear enough to continue, or you stop and re-check.
