Spreadsheet Navigation Guide

Browse the large Hoobuy spreadsheet on desktop and mobile, and narrow down to a single category.

Start wide, then narrow

A large spreadsheet is easier to use when you narrow before you read. Pick a category first, then read within it. This keeps every pass short and reviewable.

On desktop

With a wide screen you can see several columns at once. Use that to scan a category across its rows before zooming into a single candidate.

On mobile

On a small screen the same table reads better one column or one row at a time. Keep to a strict two-column category grid and scroll step by step.

desktop ↔ mobile

Narrowing to a category

  1. Open the category list and pick the group you want.
  2. Stay within that group for the whole pass.
  3. Read only the rows that match what you are looking for.
  4. Note each candidate’s origin before moving on.
